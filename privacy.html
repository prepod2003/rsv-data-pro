История изменений Политики

1. Общие положения

1.1. Настоящая Политика определяет порядок обработки персональных данных, которые Оператор получает в связи с продажей лицензий на продукт «MCP:RSV Data Pro» и поддержкой его пользователей.

1.2. Политика составлена в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных».

1.3. Политика действует совместно с Пользовательским соглашением. Принимая Пользовательское соглашение, субъект соглашается с условиями настоящей Политики.

1.4. Персональные данные обрабатываются в автоматизированных информационных системах Оператора, включая использование облачных сервисов. При использовании облачных сервисов может осуществляться трансграничная передача персональных данных с соблюдением требований законодательства Российской Федерации.

2. Кто обрабатывает данные

2.1. Оператором персональных данных является Индивидуальный предприниматель Радзивиллович Сергей Владиславович, ОГРНИП 304784735800264, ИНН 780219382520, адрес: г. Санкт-Петербург.

2.2. Обращения по вопросам обработки персональных данных направляются по контактам из раздела 12.

3. Какие данные собираются

3.1. Оператор обрабатывает минимально необходимый набор данных:

  • ✉Адрес электронной почты. Нужен, чтобы направить ключ активации, счёт и закрывающие документы, а также предупредить об окончании срока лицензии.
  • 🏢Реквизиты организации — наименование, ИНН/КПП, юридический адрес. Обрабатываются только при оплате по счёту, для выставления счёта и оформления документов.
  • 🔑Сведения о лицензии — выбранный тариф, период, дата активации и срок действия. Нужны, чтобы подтверждать право использования и обрабатывать продления.
  • 💻Технические признаки рабочего места и компьютера. Два обезличенных значения, посчитанных из настроек операционной системы: по первому лицензия соотносится с рабочим местом, по второму пробный период соотносится с компьютером. Пересчёт односторонний — восстановить по ним имя компьютера, имя пользователя операционной системы, личность, местоположение или содержимое компьютера нельзя.
  • ⚙Вид операционной системы и номер версии продукта. Передаются вместе с проверкой лицензии, чтобы ответ пришёл по правилам той версии, которая работает у Пользователя. Персональными данными не являются и с личностью не связываются.
  • 💬Контакт для связи — адрес почты или имя пользователя в Telegram, если субъект сам обратился в поддержку. Используется только для ответа на обращение.
  • 🤝Сведения для скидки владельцам MCP:RSV Server — код активации подписки на MCP:RSV Server и адрес почты, на который она оформлялась. Используются только для того, чтобы проверить при покупке, что подписка действует и по какому она тарифу, и применить соответствующую скидку.

3.2. Специальные категории персональных данных и биометрические персональные данные не обрабатываются. Данные несовершеннолетних Оператор целенаправленно не собирает.

3.3. Оператор не собирает паспортные данные, сведения о местоположении и данные банковских карт: реквизиты карты вводятся на стороне платёжного сервиса и Оператору не передаются.

4. Данные вашей информационной базы

4.1. Продукт работает на оборудовании пользователя и обращается к информационной базе по месту её размещения. Данные информационной базы — справочники, документы, суммы, сведения о сотрудниках и контрагентах — не передаются Оператору, не сохраняются и не обрабатываются на его стороне. Доступа к информационной базе пользователя у Оператора нет.

4.2. Обезличивание персональных данных включено по умолчанию: в ответах, которые получает ИИ-агент, наименования контрагентов, физических лиц и другие персональные сведения заменяются условными обозначениями. Пользователь вправе отключить обезличивание — тогда он самостоятельно определяет состав сведений, покидающих его контур.

4.3. Доступ к данным выключен из коробки: права выдаёт администратор информационной базы адресно — конкретному пользователю базы и в конкретном объёме. Действия фиксируются в журнале регистрации информационной базы, который остаётся у пользователя.

4.4. Важно об ИИ-сервисах. Полученные из базы сведения Продукт передаёт тому ИИ-сервису или программе, которые выбрал сам пользователь. Условия обработки на стороне такого сервиса определяет его поставщик; Оператор стороной этих отношений не является и за них не отвечает.

4.5. В отношении персональных данных, содержащихся в информационной базе, оператором остаётся её владелец. Оператор Продукта их обработку не осуществляет.

6. Сроки хранения

6.1. Сведения о лицензии и адрес электронной почты хранятся в течение срока действия лицензии и одного года после его окончания — этот срок необходим для подтверждения права использования при продлении или переносе лицензии. Срок действия бессрочной лицензии не ограничен, поэтому сведения о ней хранятся, пока она действует.

6.2. Документы, связанные с оплатой, хранятся в сроки, установленные законодательством о бухгалтерском учёте и о налогах и сборах.

6.3. Обращения в поддержку хранятся в течение одного года с даты последнего сообщения по обращению.

6.4. По достижении целей обработки, по истечении сроков хранения либо по отзыву согласия данные уничтожаются с составлением акта или обезличиваются, кроме случаев, когда закон требует их хранить.

7. Передача третьим лицам

7.1. Оператор не продаёт персональные данные и не передаёт их третьим лицам для рекламных целей.

7.2. Данные могут передаваться только в объёме, необходимом для исполнения договора:

  • платёжному сервису — для проведения оплаты (реквизиты банковской карты Оператор не получает и не хранит);
  • оператору электронного документооборота — для передачи закрывающих документов;
  • государственным органам — по основаниям, предусмотренным законом.

7.3. На дату настоящей редакции приём оплаты непосредственно на сайте Оператора не запущен: покупка оформляется через Оператора, а при оплате по счёту денежные средства перечисляются на его расчётный счёт. При запуске приёма оплаты на сайте платёж будет обрабатываться привлечённым платёжным сервисом, и настоящий раздел будет дополнен сведениями о нём в новой редакции Политики.

7.4. Партнёру, через которого приобретена лицензия, передаются сведения о выданном ключе, тарифе и сроке — без содержимого информационной базы клиента.

8.2. Обращение направляется по контактам из раздела 12 и рассматривается в сроки, установленные ФЗ-152.

8.3. Отзыв согласия на обработку данных, необходимых для исполнения договора, может сделать невозможным дальнейшее подтверждение права использования Продукта.

9.2. Оператор вправе подключить технические файлы cookie, необходимые для работы сайта, и сервисы сбора обезличенной статистики посещений. Такие сведения обезличены и не используются для установления личности посетителя; при их подключении настоящий раздел будет дополнен в новой редакции Политики.

9.3. Отключить cookie и локальное хранилище можно в настройках браузера; отдельные разделы сайта при этом могут работать некорректно.

10.2. Доступ к данным имеют только лица, которым он необходим для исполнения обязанностей.
